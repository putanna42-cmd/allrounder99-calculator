# Allrounder99 Calculator

Offline Android calculator suite with dark neon and light premium themes.

Tools: standard/scientific calculator, GST, EMI/loan, profit/margin/markup,
discount, simple/compound interest, commission, currency conversion, and
local history.

Open the project in Android Studio and use **Build > Build APK(s)**. The web
app files in `www/` are mirrored into `app/src/main/assets/` before building.
